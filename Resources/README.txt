MacStatus 安装说明（macOS 13 及以上，Apple Silicon）
=====================================================

首次在其他 Mac 上打开时，如果提示「Apple 无法验证 MacStatus」，
这是因为 App 使用 ad-hoc 签名（未经 Apple 公证），请用下面任一方式放行：

方式一（图形界面）
------------------
1. 把 MacStatus.app 拖到「应用程序」文件夹
2. 双击打开，弹出警告后点「完成」（不要点「移到废纸篓」）
3. 打开 系统设置 → 隐私与安全性，滚动到页面底部，
   会看到「MacStatus 已被阻止」，点旁边的「仍要打开」
4. 之后再打开不会再提示

方式二（终端，一步到位）
------------------------
打开「终端」，执行（注意 App 的实际路径）：

    xattr -cr /Applications/MacStatus.app

然后正常双击打开即可。

功能说明
--------
- 菜单栏实时显示：CPU 温度 / 内存占用% / CPU 使用% / 图标（可在面板底部切换）
- 点击菜单栏图标弹出面板：CPU 温度与使用率、内存、风扇、传感器温度、
  内存占用 Top5 应用
- 数据来自 SMC 与系统原生接口，无需 root 权限
- 偏好自动持久化；退出按钮在面板底部
